Dados pessoais que coletamos A Visual Studio And Security coleta dados de usuários, por meio de suas interações conosco e do uso de nossos produtos. Você fornece alguns desses dados diretamente e obtemos outros dados coletando informações sobre suas interações, uso e experiências com nossos produtos. Os dados que coletamos dependem do contexto de suas interações com a Microsoft e as opções que você escolhe, incluindo as suas configurações de privacidade e os produtos e recursos que você usa. Também obtemos dados sobre usuários de afiliadas, subsidiárias e terceiros da Visual Studio And Security. Você tem opções quando se trata dos dados que compartilha. Quando pedimos que forneça os seus dados pessoais, você pode recusar. Você também pode usar controles no produto, incluindo aqueles em seu navegador da Web ou sistema operacional para limitar ou impedir determinados tipos de coleta de dados. Muitos dos nossos produtos exigem alguns dados pessoais para que o serviço seja oferecido. Se você optar por não fornecer ou nos permitir coletar os dados necessários, não poderá usar o produto ou recurso relacionado. Da mesma forma, quando precisamos coletar dados pessoais por lei ou entrar ou executar um contrato com você e você não fornecer os dados, não será possível entrar ou executar o contrato. Quando o fornecimento dos dados é opcional e você opta por não compartilhá-los, recursos como personalização que usam esses dados não funcionarão para você. Como utilizamos dados pessoais A Visual Studio And Security usa os dados que coletamos para proporcionar experiências sofisticadas e interativas. Especificamente, usamos dados para: Fornecer nossos produtos, que incluem atualização, proteção e solução de problemas, além de fornecer suporte e fazer recomendações.Melhorar e desenvolver nossos produtos. Como parte dos nossos esforços para melhorar e desenvolver os nossos produtos, poderemos utilizar os seus dados para desenvolver e treinar os nossos modelos de IA. Saiba mais aqui. Anunciar e comercializar para você, o que inclui enviar comunicações promocionais, publicidade Personaliza das e apresentar ofertas relevantes.também usamos os dados para operar nossos negócios, incluindo a análise de nosso desempenho, o cumprimento de nossas obrigações legais,o desenvolvimento de nossa força de trabalho e a realização de pesquisas. Cookies de terceiros podem ser usados para fins necessários para fornecer o site ou serviço, para mostrar anúncios e conteúdo com base em seus perfis de mídia social e atividades em nossos sites, para entender melhor como você e outras pessoas usam nossos sites para que possamos melhorá-los e para que os terceiros possam melhorar seus próprios produtos e serviços, e para mostrar anúncios relevantes para você. Você pode controlar os dados coletados por cookies, web beacons e tecnologias semelhantes. Por exemplo, você pode usar controles em seu navegador da Internet para limitar como os sites que você visita podem usar, limpar ou bloquear cookies. Quando necessário, obtemos seu consentimento antes de colocar ou usar cookies opcionais que não são (i) estritamente necessários para fornecer o site ou serviço; ou (ii) para facilitar uma comunicação. Quando o consentimento for necessário, você poderá retirar o consentimento para cookies opcionais clicando em "Gerenciar cookies" no rodapé do site.
