Dados pessoais que coletamos

A Visual Studio And Security coleta dados de usuários por meio de suas interações conosco e do uso de nossos produtos. Você fornece alguns desses dados diretamente e obtemos outros dados coletando informações sobre suas interações, uso e experiências com nossos produtos. Os dados que coletamos dependem do contexto de suas interações com a Microsoft e das opções que você escolhe, incluindo as suas configurações de privacidade e os produtos e recursos que você usa. Também obtemos dados sobre usuários de afiliadas, subsidiárias e terceiros da Visual Studio And Security.

Você tem opções quando se trata dos dados que compartilha. Quando pedimos que forneça os seus dados pessoais, você pode recusar. Você também pode usar controles no produto, incluindo configurações de privacidade, para gerenciar como esses dados são usados. Em alguns casos, o compartilhamento de determinados dados é opcional e você pode optar por não compartilhá-los; nesse caso, recursos como personalização que usam esses dados não funcionarão para você.

Como utilizamos dados pessoais

A Visual Studio And Security usa os dados que coletamos para proporcionar experiências sofisticadas e interativas. Especificamente, usamos dados para fornecer nossos produtos, que incluem suporte, atendimento, segurança e melhoria contínua. Também usamos os dados para desenvolver e treinar nossos modelos de IA, anunciar e comercializar para você, enviar comunicações promocionais, publicidade personalizada e apresentar ofertas relevantes. Além disso, usamos os dados para operar nossos negócios, incluindo a análise do nosso desempenho, o cumprimento de nossas obrigações legais, o desenvolvimento da nossa força de trabalho e a realização de pesquisas.

Cookies de terceiros podem ser usados para fins necessários para fornecer o site ou serviço, para mostrar anúncios e conteúdo com base em seus perfis de mídia social e atividades em nossos sites, e para medir a eficácia de campanhas e conteúdos.

Você pode controlar os dados coletados por cookies, web beacons e tecnologias semelhantes. Por exemplo, você pode usar controles em seu navegador da Internet para limitar como os sites que você visita usam cookies e outras tecnologias de rastreamento.
